# Sweepy — demo videos

Sweepy finds duplicate files, old installers and big files on your Mac. Every cleanup goes to the Trash and can be undone.
Free on the Mac App Store · [oneclicktool.app/macos/sweepy](https://oneclicktool.app/macos/sweepy)
